========================================
  Product Matching Program (React)
========================================

QUICK START:
========================================
1. Double-click "INSTALL.bat"
   (First time only, 2-3 minutes)

2. Double-click "START-ALL.bat"
   (Opens 2 windows + browser)

3. Use the app at http://localhost:3000


FILES:
========================================
INSTALL.bat      - Install packages (first time)
START-ALL.bat    - Start both servers


MANUAL INSTALLATION:
========================================
If batch files don't work, use Command Prompt:

Step 1:
  cd /d "C:\Users\pc\Desktop\product-matching-react"
  npm install

Step 2:
  cd backend
  npm install


MANUAL START:
========================================
Backend (Terminal 1):
  cd /d "C:\Users\pc\Desktop\product-matching-react\backend"
  npm start

Frontend (Terminal 2):
  cd /d "C:\Users\pc\Desktop\product-matching-react"
  npm start


TROUBLESHOOTING:
========================================
Q: "npm is not recognized"
A: Install Node.js from https://nodejs.org

Q: Installation fails with errors
A: Run Command Prompt as Administrator

Q: Port already in use
A: Close other instances or restart PC

Q: Google Sheets connection error
A: Check backend\config\Google Sheets API.json
